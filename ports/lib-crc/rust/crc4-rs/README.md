# crc4-rs

Rust port of `crc4.c`, bridged with the C ABI. Generated by rust-anything.

## Functions

- `crc4` (`crc4.c:26`)

## Corpus note

`c` is a running 4-bit CRC — contract domain 0..=15. The auto-generated
corpus included 157/222 cases with `c > 15`, where the C reads past the
16-entry `crc4_tab` (out-of-bounds read, layout-dependent UB — the
recorded values were `.rodata` padding/adjacent objects, not algorithm
behavior). Those inputs were constrained to `c & 15` before recording,
keeping full `x`/`bits` coverage including `bits` = 0, negative,
`INT_MAX` (the port mirrors x86-64 masked-shift semantics for
out-of-range `bits`). Divergence: for `c > 15` the verification crate
panics via bounds-checking where C had UB; `klib::crc::crc4` masks the
index to 4 bits instead — both documented choices for undefined input.

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```

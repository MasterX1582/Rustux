# wrappers-rs

Rust port of `wrappers.c`, bridged with the C ABI. Generated by rust-anything.

The port is split in two, mirroring the two C layers it replaces:

- `../maple-model` — safe Rust model of upstream `lib/maple_tree.c` semantics
  (canonical 256-byte pool nodes, `mas_*`/`mtree_*` API), `#![forbid(unsafe_code)]`.
- `src/port.rs` — the `wrappers.c` layer: op drivers, canonical dumps, and the
  `wrap_mt_*` FFI functions, also `#![forbid(unsafe_code)]`.

## Functions

- `wrap_mt_seq` (`wrappers.c`)
- `wrap_mt_area` (`wrappers.c`)
- `wrap_mt_iter` (`wrappers.c`)

## Loop

```sh
rust-anything record .   # record what the C code does
rust-anything build .    # build the C ABI module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```
